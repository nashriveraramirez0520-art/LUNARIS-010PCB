# LUNARIS-01 PCB 🚀

LUNARIS-01 is my first custom PCB, designed in KiCad as part of Hack Club's Starbie project.

I started by following the Starbie guide to learn the basics of schematic design, footprint assignment, PCB layout, and routing. As I worked on the board, I decided to give the project its own identity by redesigning the board outline into a spacecraft inspired by LUNARIS-01, a spaceship from another project I am developing.

## Features

- Seeed Studio XIAO ESP32-C3
- DHT11 temperature and humidity sensor
- I2C OLED display
- MPU6050 connector
- Two mechanical switches
- Custom spacecraft-shaped PCB outline
- Custom LUNARIS-01 silkscreen artwork
- Fully routed PCB with 0 unrouted connections

## Design

The schematic and PCB were designed using KiCad. During routing, I reorganized several components to make the layout work within the custom spacecraft shape.

The final board also includes a custom Saturn-inspired graphic and LUNARIS-01 branding on the silkscreen.

## Project Files

- `Starbie.kicad_sch` — Schematic
- `Starbie.kicad_pcb` — PCB layout
- `Starbie.kicad_pro` — KiCad project
- `Imported Parts.pretty/` — Custom footprints
- `Seeed_Studio_XIAO_Series.kicad_sym` — XIAO symbol library
